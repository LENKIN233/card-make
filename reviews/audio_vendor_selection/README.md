# 音频供应商盲听选型记录

这里保存重新生成 CET 音频前的供应商盲听证据。固定题组为
`CASES.json`：对话、独白、弱读、连读、易错发音各 4 条，共 20 条。

流程必须保持匿名：先只按 `blind_id` 生成和评分，人工审核者锁定每条
1–5 分与 blocker 后，才填写 `unblinding.mapping`。候选平均分不低于
4/5 且 blocker 为 0 才有资格入选；最高分胜出，同分时优先
`tencent_cloud`，仍同分则按 `blind_id` 排序，保证结果可重复。

从 `TEMPLATE.json` 复制真实记录，不要修改模板本身。完成记录必须绑定题组
哈希、20×候选数个音频文件哈希、人工审核人和评分时间。揭盲映射还必须
记录供应商、模型、音色、速度、生成时间和版本；每条资产分别绑定
transcript SHA-256 与文件 SHA-256。然后运行：

```bash
node scripts/validate_audio_vendor_selection.mjs
```

校验器只验证证据完整性和计算结果，不生成听感分数。通过选型也不等于
301 条资源已经通过逐卡音频 QC，更不构成内容批准。
